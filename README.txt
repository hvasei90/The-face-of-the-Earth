زمین‌نما — آزمایشگاه سه‌بعدی چهرهٔ زمین

محتویات:
- index.html : ساختار صفحه و بخش‌های آموزشی
- style.css : ظاهر واکنش‌گرا و راست‌چین
- app.js : صحنه‌های سه‌بعدی و کنترل‌های تعاملی مبتنی بر Three.js

روش اجرا:
1) هر سه فایل را در یک پوشه نگه دارید.
2) برای اجرای مطمئن، پوشه را با یک سرور محلی باز کنید؛ مثلاً در VS Code افزونه Live Server را اجرا کنید.
3) اتصال اینترنت لازم است، چون Three.js و فونت از CDN بارگیری می‌شوند.
4) برای انتشار در GitHub Pages، هر سه فایل را در ریشهٔ مخزن قرار دهید و index.html را صفحهٔ اصلی بگذارید.

نکته: مدل‌ها آموزشی و مفهومی‌اند؛ مقیاس‌ها و حرکت‌ها برای قابل‌درک‌کردن فرایندها ساده‌سازی شده‌اند.
