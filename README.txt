زمین‌نما — آزمایشگاه سه‌بعدی چهرهٔ زمین

اجرا:
1) همه فایل‌ها را در یک پوشه نگه دارید.
2) پوشه را در VS Code باز کنید.
3) با افزونه Live Server فایل index.html را اجرا کنید.
4) برای بارگذاری Three.js و فونت، اتصال اینترنت لازم است.

به‌روزرسانی‌ها:
- صحنهٔ سه‌بعدی با اندازهٔ viewport هماهنگ می‌شود و دوربین به مرکز مدل نگاه می‌کند.
- انتخاب سنگ‌کره، آب‌کره و هواکره نمای سه‌بعدی را عوض می‌کند.
- ارتفاع ناهمواری‌ها با لغزنده تغییر می‌کند.
- کوه جوان با قله‌های نوک‌تیز، دامنه‌های پرشیب و درهٔ V شکل و کوه پیر با قله‌های گردتر، دامنه‌های ملایم و درهٔ بازتر نمایش داده می‌شود.
- حرکت ورقه‌های دورشونده دارای مرحله‌بندی نمایشی برای بالا آمدن ماگما، سردشدن و تشکیل پوستهٔ تازه است.
- فرایندهای درونی، بیرونی و فعالیت‌های انسانی کنترل مرحله/پخش دارند.

توجه: مدل‌ها برای تدریس مفهومی ساده‌سازی شده‌اند و شبیه‌سازی عددی دقیق زمین‌شناسی نیستند.
