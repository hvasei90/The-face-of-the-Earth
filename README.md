# چهره زمین — آزمایشگاه سه‌بعدی

سایت فارسی و راست‌چین با ۹ صحنهٔ سه‌بعدی تعاملی. فایل‌های اجرایی در `dist` قرار دارند.

## اجرا

در پوشهٔ `dist` یک وب‌سرور محلی اجرا کنید، مثلاً:

    python -m http.server 8000

سپس `http://localhost:8000` را باز کنید. به دلیل استفاده از ماژول‌های JavaScript، فایل index.html را با دابل‌کلیک باز نکنید. در VS Code نیز Live Server قابل استفاده است. برای میزبانی استاتیک، محتوای dist را بارگذاری کنید.

فایل‌های Three.js، کنترل دوربین، فونت و بافت کره زمین محلی هستند. پس از دریافت کامل فایل‌ها، اجرای محلی به CDN نیاز ندارد. مرورگر باید WebGL و import maps را پشتیبانی کند.

## استفاده

- یک فرایند را از فهرست انتخاب کنید.
- شروع/توقف، اجرای مجدد و سرعت پخش در پایین مدل قرار دارد.
- لغزندهٔ زمان و دکمه‌های «قبل» و «بعد» شکل مدل را تغییر می‌دهند.
- کشیدن ماوس یا انگشت: چرخش. چرخ ماوس یا حرکت دو انگشت: زوم.
- دکمهٔ هدف: بازگشت به نمای اولیه. دکمهٔ تمام‌صفحه برای تدریس.
- در مقایسهٔ کوه‌ها، مدل مرجع ثابت و مدل دوم قابل فرسایش است.

## مدل آموزشی

شبیه‌سازی‌ها مفهومی و مبتنی بر تغییر هندسه و ذرات‌اند؛ محاسبات پیش‌بینی عددی زمین‌شناسی نیستند. مقیاس زمان و ابعاد برای آموزش تغییر کرده است. نرم‌کره عمدتاً جامد است. درهٔ U حاصل معمول فرسایش یخچالی است، نه شاخص قطعی سن کوه.

## بررسی انجام‌شده

`node tests.mjs` در پوشهٔ منبع، ۶۳ وضعیت از ۹ صحنه را از نظر داده‌های هندسی متناهی، اندیس‌های هندسی، تغییر واقعی حالت، بازگشت‌پذیری نوار زمان و بازنشانی بررسی می‌کند. بررسی نحوی فایل‌های JavaScript نیز انجام شده است.

تأیید بصری در مرورگر و آزمایش تعاملی روی دستگاه واقعی در محیط ساخت انجام نشده است.
